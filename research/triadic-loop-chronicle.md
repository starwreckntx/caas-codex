## Hypothesis
Creative collaboration between human artists and multi-model AI agents can be
described as a **triadic loop**: observe → synthesize → revise, with each pass
preserving aesthetic intent while expanding formal technique.

## Protocol axioms
1. **No personal transcripts in-repo** — working dialogue stays in private notes
   or encrypted operator stores; the public tree holds only methodological residue.
2. **Hypothesis before anecdote** — chronicle entries record claims, tests, and
   outcomes; not private conversation.
3. **Reproducible prompts only** — publish prompt schemas and evaluation rubrics,
   not one-off chat dumps.
4. **Consent & attribution** — credit human and model roles without exposing
   private identifiers.
